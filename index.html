Find Compatible Players

This feature will be built in Phase 5. It will allow you to select a proposed lesson time slot (e.g. Wednesday morning), format (e.g. 1:3), and target level range (e.g. 2.0 – 2.5), and instantly surface all matching students with overlapping availability and compatible ratings.

Matching Algorithm Rule:

A student matches when their acceptable level range [StudentMin, StudentMax] overlaps with your proposed session range [SessionMin, SessionMax].

How to link your Supabase project:

  1. Create a copy of .env.example named .env in your project root.
  2. In your Supabase dashboard, go to Project Settings → API.
  3. Copy your Project URL and anon (public) key into your .env file.
  4. Restart the Vite server (or save the file) and refresh this page.
